# HU-003: Estimación y actualización automática del riesgo

| ID | Prioridad | Puntos | Depende de | Paso del sprint |
|---|---|---|---|---|
| HU-003 | Alta | 5 | HU-002 | 4 (junto con HU-004) |

## Descripción (del documento)

Como coordinador/a del Programa de Tutorías, quiero que el riesgo de abandono de cada
estudiante se recalcule automáticamente cada vez que se incorporan datos, para contar con
alertas actualizadas antes del inicio del período siguiente.

## Criterios de aceptación (del documento)

1. Dado que existe un modelo habilitado, cuando finaliza una carga de datos válida,
   entonces la plataforma calcula, sin intervención manual, la probabilidad de abandono de
   cada estudiante incorporado.
2. Dado que la carga corresponde a un momento del período académico, cuando se calcula el
   riesgo, entonces se utiliza el modelo correspondiente a ese momento.
3. Dado que un estudiante ya tenía un riesgo calculado, cuando se recalcula, entonces el
   nuevo valor reemplaza al vigente y el anterior se conserva en su historial.
4. Dado que se completó el cálculo, cuando un usuario consulta la plataforma, entonces se
   muestran la fecha de la última actualización y la versión del modelo utilizada.
5. Dado que no hay un modelo habilitado, cuando finaliza una carga, entonces no se
   calculan riesgos y se informa el motivo al Área de Sistemas.

## Notas de implementación

- El servicio de predicción lee el modelo habilitado del momento (tabla MODELO +
  `modelos/<momento>/vX/`), arma el DataFrame con las variables del momento desde
  ESTUDIANTE y RENDIMIENTO_SEMESTRE, y calcula probabilidad, nivel (HU-004) y los cinco
  factores SHAP (tarea 6.1, ya resuelta en HU-002) en una sola pasada.
- **Recálculo en segundo plano** al terminar una carga válida (planificador): la pantalla
  de carga muestra «en curso» y luego «Completado: modelo vX (momento)».
- Historial: la predicción anterior queda con `vigente = false`; la nueva, `true`. En una
  transacción.
- Sin modelo habilitado: la carga se registra, no se calcula nada y el resultado de la
  carga dice el motivo (criterio 5).

## Pruebas por criterio

| Criterio | Prueba |

| 1 | Carga válida con modelo habilitado → cada estudiante incorporado tiene una predicción vigente, sin llamadas manuales |
