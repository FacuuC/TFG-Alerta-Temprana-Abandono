## Descripción (del documento)

Como integrante del Área de Sistemas de Información, quiero entrenar el modelo con los
datos históricos y evaluar su desempeño, para habilitar las alertas solo cuando el modelo
alcance el desempeño esperado.

## Criterios de aceptación (del documento)

1. Dado que hay datos históricos con la situación final de cada estudiante, cuando se
   ejecuta el entrenamiento, entonces la variable objetivo distingue el abandono del no
   abandono (graduado o sigue cursando) y los datos se dividen en forma estratificada en
   entrenamiento (60 %), validación (20 %) y prueba (20 %).
2. Dado que el riesgo se calcula en distintos momentos del período académico, cuando se
   entrena, entonces se obtiene un modelo para cada momento que usa solo las variables
   disponibles en ese momento.
3. Dado que los modelos fueron ajustados con el conjunto de validación, cuando se evalúan
   sobre el conjunto de prueba, entonces se informan el AUC-ROC, la precisión y la
   sensibilidad de cada momento. El modelo del cierre del primer semestre se habilita solo
   si su AUC-ROC supera el 0,80, y los otros dos se habilitan con el desempeño obtenido,
   que queda informado.
4. Dado que el modelo fue evaluado, cuando se presentan los resultados, entonces se
   informan el AUC-ROC, la sensibilidad y la precisión por subgrupos (género, edad de
   ingreso y condición de becario) y el AUC-ROC calculado sin quienes siguen cursando.
5. Dado que el modelo fue habilitado, cuando se guarda, entonces queda registrado con un
   número de versión, la fecha y sus métricas.
