# HU-005: Listado de alertas tempranas

| ID | Prioridad | Puntos | Depende de | Paso del sprint |
|---|---|---|---|---|
| HU-005 | Alta | 5 | HU-004 | 5 |

## Descripción (del documento)

Como coordinador/a del Programa de Tutorías, quiero consultar las alertas ordenadas por
nivel de urgencia y filtrarlas, para planificar el acompañamiento de los estudiantes.

## Criterios de aceptación (del documento)

1. Dado que existen alertas generadas, cuando el coordinador ingresa al listado, entonces
   las alertas se muestran ordenadas por nivel, con el nivel alto primero, y dentro de cada
   nivel por probabilidad, de mayor a menor.
2. Dado que se muestra el listado, cuando se revisa cada alerta, entonces se ven el código
   del estudiante, su carrera, el nivel, la probabilidad y el estado de seguimiento, sin
   datos que lo identifiquen.
3. Dado que el coordinador necesita acotar la búsqueda, cuando filtra por carrera, turno,
   nivel o estado de seguimiento, entonces el listado muestra solo las alertas que cumplen
   esos criterios.
4. Dado que el nivel se muestra en pantalla, cuando se visualiza, entonces se indica con
   color y con texto, para que su lectura no dependa solo del color.

## Pruebas por criterio

| Criterio | Prueba |
|---|---|
| 1 | Con alertas sintéticas, el orden es alto → medio → bajo y, dentro de cada nivel, probabilidad descendente |
| 2 | Las columnas devueltas son exactamente código, carrera, turno, nivel, probabilidad y estado (+ id para la ficha); ninguna identificatoria |
| 3 | Cada filtro, solo y combinado, devuelve únicamente las filas que cumplen |
| 4 | El componente del nivel tiene texto («Alto», «Medio», «Bajo») además del color (verificación del layout) |
